THE POCKET CHEAT SHEET

A few words.
A lot less squinting. 👀

A small, fixed English vocabulary. Every supported instruction has an exact meaning.

Read the full syntax guide ↗

Raw regex is not rule text; a supported subset translates back into rules. Alternation, lookaround and backreferences are rejected.

start / end→^ / $
3 digits→\d{3}
between 2 and 6 digits→\d{2,6}
letters→[A-Za-z]+
lowercase letters / uppercase letters→[a-z]+ / [A-Z]+
6 hex digits→[0-9A-Fa-f]{6}
"hello"→hello
one of: a, b→[ab]
text without: a, b→[^ab]*
any text→.*
