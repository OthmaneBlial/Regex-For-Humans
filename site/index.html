THE POCKET CHEAT SHEET

A few words.
A lot less squinting. 👀

A small, fixed English vocabulary. Every supported instruction has an exact meaning.

Read the full syntax guide ↗

JavaScript RegExp only. Free-form English, raw regex, groups, alternation, and lookaround aren't part of this language.

start / end→^ / $
3 digits→\d{3}
between 2 and 6 digits→\d{2,6}
letters→[A-Za-z]+
6 hex digits→[0-9A-Fa-f]{6}
"hello"→hello
one of: a, b→[ab]
text without: a, b→[^ab]*
any text→.*
