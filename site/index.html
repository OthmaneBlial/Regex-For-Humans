ANCHORSstart→^
CHARACTERdigit→\d
REPETITION3 digits→\d{3}
LITERAL"ABC"→ABC
CHARACTER SETone of: a, b→[ab]
ANY TEXTany text→.*
EXCLUSIONtext without: a, b→[^ab]*

Built for JavaScript RegExp. Arbitrary English, groups, alternation, lookaround, and raw regex are outside the current language.
