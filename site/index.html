Name the parts you capture.

Named captures are native JavaScript groups, written as readable rules you can edit.

Rules

A named group gives you a field. A numbered capture keeps its position. A noncapturing group keeps a block together.

JavaScript regex
/^(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})$/u

This checks a date shape, including impossible dates. Validate calendar values separately. Groups, captures, backward references and ordered alternatives are included in npm 0.1.0-dev.12.

Raw regex is not rule text; a supported subset translates back into rules. Groups and ordered alternatives are supported; forward/open capture references are rejected.

Questions

Does it understand any English sentence?

It uses a fixed, documented vocabulary. Unknown instructions receive a line, column and repair hint. There is no AI interpretation or remote prompt.

Can I import every regex?

The translator accepts the documented native JavaScript subset: groups, captures, ordered alternatives, backward references, lazy repetition, lookahead/lookbehind, word boundaries, Unicode properties/classes and v-mode strings and nested sets. Empty sets require v mode. Forward/open references, empty u-mode classes and other-engine constructs receive diagnostics. Unsupported syntax is never silently removed.

Can flags apply to just one group?

Use group with flags "i" { to ignore case inside one block; closing it restores the enclosing options. Local i/m/s flags also work with nested groups, captures and reverse translation. They require a compatible native engine: verified browser Unicode modes pass, while tested Node 22/25/26 editions receive an explicit unsupported-feature error. Cached source cannot bypass that check. Read the syntax and runtime limits.

Are my test strings sent anywhere?

The workshop matches in your browser's isolated worker. Rules and examples stay local. The page and its static assets are served by the hosting provider; no application backend receives your matching inputs.

Does a passing example prove a regex is safe?

Examples establish selected behavior. The workshop bounds input and terminates a worker after 1,200 ms. A regex copied into another application needs that application's own execution safeguards.

Which version should I use?

npm 0.1.0-dev.12 is the development preview. The library and CLI compile whole-line comments and support group editing, SVG structure diagrams, risk notes and nine programming-language export formats. The workshop adds rule templates, syntax colors, validated class and closed-capture-reference completion with a complete rule preview, exact span/capture/replacement expectations, fixture files and local save/restore, and reproducible Markdown reports. Reports contain intended tests without running or certifying them. Optional draft recovery and before/after group-edit previews retain the current workspace until an edit is applied. Explore 31 searchable recipes, failure explanations and beginner/intermediate/expert notes. Precise quoted/property/class diagnostic ranges, input-edge failure explanations and complete snapshot links are included alongside aggregate result limits and efficient multiline paste handling. Four interface languages and system, light and dark themes are available. Install regex-for-humans@preview or try the browser workshop. Node.js 22+ is required by the library and CLI. Engine limitations are reported explicitly. Seven foreign-engine corpora pass, including PHP 8.5.11 / PCRE2 10.44; validate other editions. Human usability and screen reader reviews remain open.
