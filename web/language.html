A complete rule

start "ABC"
3 digits
end
GENERATES/^ABC\d{3}$/u

Matches ABC123
Rejects ABC12, ABC1234

Use line start and line end for line-based matching. Line anchors add JavaScript's m flag. Input and line anchors cannot be mixed.

Without m, start and end match only the true input edges. They reject a final line break; m makes line anchors match each line.

04

BOUNDARIES

Flags and limits

u always

Unicode regex mode is always enabled.

i and s optional

Choose ignore case or dot matches newlines in the workshop or CLI.

m from line anchors

Line anchors enable multiline behavior automatically.

Rules are limited to 16,384 UTF-16 code units, 200 lines and numeric repetition counts up to 1,000. The workshop limits example strings and runs matching in a time-limited worker. These limits do not guarantee that a copied regex is fast in another program.

Groups, alternation, lookaround, raw regex injection and other regex engines are outside this language version. Read the full language contract ↗, or the local Markdown source ↗ when offline.
