Scope: homepage (Persuade); the workshop (Operate) later inherits the palette and type only. Audience: JavaScript developers who need to write a regex now, or understand one they were handed. Action: paste a regex or write rules in the first viewport, then install or open the workshop.

## Direction contract

THESIS: The product is a translator, so the page is an interlinear edition. A regex is set as the source line; under each fragment sits its plain-English gloss, and under that the characters it matched. Grammatical words (START, END, CAPTURE, OR) are small caps, as in linguistic glossing. Refuses the dev-tool template (dark hero, split code panes, feature-card rows) and any borrowed metaphor.

OWN-WORLD: White paper, near-black ink, one ultramarine for connecting hairlines, the active column and links, a pale ultramarine wash for matched text. Source Serif 4 for prose and glosses with true small caps; JetBrains Mono only for regex, rules and code. Hairline braces join fragment to gloss; group spans are brackets under their columns. Numbered examples (1), (2)… as in a linguistics paper. No cards, no shadows, no rounded panels; rules and whitespace carry structure.

STORY: The visitor reads a real regex glossed word by word, watches several examples translate in turn, pastes their own regex or writes rules and sees the same gloss, tests text, then copies, installs or opens the workshop.

FIRST VIEWPORT: Slim header (wordmark, Recipes, Docs, GitHub, Open the workshop). Two-line serif headline "Write regex in plain English. Read any regex the same way." with one sentence. Full-width interlinear example (regex row 40px mono, gloss row, bracket rows, matched-text row) with numbered example selectors and a pause control. Directly under it: Explain / Write input and the test-text field.

FORM: Interlinear gloss / bilingual edition, IMPECCABLE'S PICK (user-chosen), position 1 on the ordered list. seed:00c5a6a0a1314896
