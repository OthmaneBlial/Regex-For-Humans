Scope: homepage (Persuade) and the shared visual world later carried into the workshop (Operate). Audience: JavaScript developers who can say what they want to match but not write the regex.

## Direction contract

THESIS: Regex already has a native drawing, the railroad diagram; Regex For Humans draws every pattern as one transit line. Each readable rule is a station, each station shows its regex fragment, and a test string rides the line. Refuses the dev-tool template: headline, split code panes, a row of feature cards, emoji badges.

OWN-WORLD: White enamel-sign ground, near-black ink, thick rounded line strokes, white station discs with black rings, interchange pills. Line colours carry jobs: red for literal text, blue for character sets, green for repetition loops, amber for captures, violet for choices, black terminus bars for anchors. Bricolage Grotesque as signage voice, tight and bold; code in the system mono. No cards with shadows; panels are flat sign plates with 2px ink borders.

STORY: The visitor sees a pattern drawn as a line, types into it, watches which station consumes which characters, understands that rules map to regex fragments, then opens the workshop or installs the package.

FIRST VIEWPORT: Top bar (wordmark as a line terminus, links, "Open the workshop"). Left third: headline "Regex you can read like a map." with one sentence and two actions. Right two thirds: the live line for the selected recipe (three recipe pills like line selectors), stations with rule above and fragment below, the full regex as a destination board, and the test input with per-station character highlights.
